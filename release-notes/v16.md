# Barrelbot v16

Paper 26.3 classroom release. Install the classroom plugin, datapack, and client resource pack together. See [the classroom guide](../CLASSROOM.md) for Maryville import, lane setup, builder and partner controls, row previews, and setup undo.

The versioned pack sources for this release are in `build/barrelbot_data_pack` and `build/barrelbot_resource_pack`. The classroom plugin is in `classroom/src/main`. The historical Beet project and 1.21.11 migration scripts remain available for reference.


## Verification

The Paper integration exercise uses a disposable copy of the 2026 reset-day world. It checks a 40-lane row repair and addition, lane 2 testing, row reset, clone overwrite, cascade, setup undo, dispenser start and stop, and the classroom import. Separate simulated accounts exercise builder locking, partner recall, denied learner clone access, creative feature placement, and returning an instruction before a world change.
